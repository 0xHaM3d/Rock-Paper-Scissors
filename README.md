# 🎮 Rock–Paper–Scissors
A simple and interactive **Rock–Paper–Scissors** game built with **Python** and **Streamlit**.
Play 10 rounds against the computer, track your score in real time, and enjoy smooth UI animations.

## 🚀 Features
 - Interactive Streamlit UI

 - 10‑round gameplay

 - Live scoreboard (player wins, computer wins, ties)

 - Animations for computer choice and final celebration

 - Dark/Light mode toggle

 - Clean and modular game logic using OOP

## 📦 Installation
```Bash
git clone https://git@github.com:0xHaM3d/Rock-Paper-Scissors.git
cd rock-paper-scissors-streamlit
pip install -r requirements.txt
```

## ▶️ Run the App
```Bash
streamlit run app.py
```
